# عثمان المشاقبة · Othman Almashaqba

الموقع الشخصي لعثمان المشاقبة، قائد تقنية في الرياض: استراتيجية التقنية، وتحولات ERP على Odoo من الإصدار 8 إلى 19، وحوكمة تقنية المعلومات.

**الرابط:** https://nouraldeentofi.github.io/othman-almashaqba/

موقع ثابت من ست صفحات بالعربية (افتراضيًا، من اليمين إلى اليسار) والإنجليزية بزر واحد، مبني بـ HTML وCSS وJavaScript فقط، بلا أطر عمل. فيه وضع فاتح (افتراضي) وداكن، ويتذكر اختيار الزائر للغة والوضع.

## الفكرة

خيوط تدخل متشابكة من بداية السطر، وتخرج مستقيمة ومرتبة في نهايته: هكذا يعمل عثمان، يرتّب العملية قبل أن يؤتمتها. في الصفحة الرئيسية تمر الخيوط خلف صورته وتخرج مسارات منتظمة، وفي رأس كل صفحة شريط منها، وكلما نزل الزائر في الصفحة استقامت أكثر. الألوان من صورته وغلاف حسابه: كحلي البدلة، وأزرق القميص، وخشب الجوز خلفه.

## الصفحات

| الصفحة | ما فيها |
|---|---|
| `index.html` الرئيسية | الاسم والجملة التي تعرّفه وصورته، ثم قناعته في سطر، وأرقام قبل التقنية وبعدها، وخمس أفكار تتبدل وحدها، ومحطات الرحلة، ومقياس Odoo من 8 إلى 19، والأبحاث |
| `story.html` القصة | مسيرته من 2010 حتى اليوم كقصة واحدة على خيط: جامعة آل البيت، اليونيسف، Shahwan، دبي، الأردن، مجموعة العمران، Meela |
| `approach.html` المنهج | العدسة التي تكبّر ما تجده، ونسبة 80/20، والخطوات الأربع، وما يتمسك به، والأطر (COBIT وITIL وISO 27001) |
| `work.html` الأعمال | البرامج على مقياس الإصدارات، وبطاقات البرامج، وخريطة الوحدات الاثنتي عشرة حول Odoo، والنتائج، والمجالات الستة |
| `knowledge.html` المعرفة | الدراسة، والأبحاث المقدّمة للنشر، والشهادات، واللغات، وما يتابعه الآن |
| `contact.html` تواصل | يختار الزائر موضوعًا فيفتح بريده والموضوع والتحية جاهزان، وبطاقات التواصل، وأسئلة شائعة |

## تعديل النصوص

كل النصوص في `build.py`، بالعربية ثم الإنجليزية. عدّل فيه ثم شغّل:

```bash
python3 build.py
```

فيُعاد توليد الصفحات الست و`404.html` و`llms.txt` و`llms-full.txt` و`robots.txt` و`sitemap.xml`.

## CONFIG

في أعلى `build.py`:

| المفتاح | عمله |
|---|---|
| `BASE_URL` | عنوان الموقع، تُبنى منه الروابط الأساسية وخريطة الموقع |
| `PROTOTYPE` | ما دامت `True` لا تفهرس محركات البحث الموقع. بعد موافقة عثمان اجعلها `False` وأعد البناء |
| `PHOTO` | الصورة الشخصية |
| `EMAIL`، `PHONE`، `PHONE_SHOW` | البريد والهاتف كما يظهران في الموقع |
| `WHATSAPP` | رقم واتساب بأرقام دولية فقط (مثل `966595094009`). إن بقي فارغًا لا يظهر زر واتساب |
| `LINKEDIN` | رابط حسابه |
| `MAKER` | رابط المصمم في تذييل الصفحات |

أي قيمة فارغة تختفي من الموقع.

## للمساعدات الذكية ومحركات البحث

كل المحتوى موجود في HTML نفسه. في كل صفحة بيانات schema.org (Person وWebSite وBreadcrumbList، وFAQPage في صفحة التواصل مطابقة للأسئلة الظاهرة)، ومعها `llms.txt` و`llms-full.txt` و`robots.txt` الذي يرحب بـ GPTBot وClaudeBot وPerplexityBot وGoogle-Extended، و`sitemap.xml`.

## نطاق خاص لاحقًا

**على GitHub Pages نفسه:** من الإعدادات → Pages → Custom domain، اكتب النطاق، ثم أضف عند مزود النطاق سجل CNAME يشير إلى `nouraldeentofi.github.io`. بعدها اجعل `BASE_URL` في `build.py` هو النطاق الجديد، وأعد البناء وارفع التغييرات.

**أو على Cloudflare Pages:** Workers & Pages → Create → Pages → Connect to Git → اختر هذا المستودع. الإطار: None، أمر البناء فارغ، مجلد الإخراج `/`. بعد أول نشر: Custom domains → أضف النطاق، ثم غيّر `BASE_URL` وأعد البناء.
